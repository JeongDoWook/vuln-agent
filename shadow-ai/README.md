# 섀도우 AI DLP (Chrome 확장 PoC)

`vuln-agent` 저장소의 사이드 PoC. ChatGPT/Claude/Gemini 같은 AI 챗봇 입력창에
직원이 민감정보(주민등록번호, 카드번호, API 키 등)를 붙여넣거나 입력하는 순간을
**브라우저단에서 탐지·기록(·경고)** 하는 Manifest V3 확장 프로그램이다.
"프롬프트 단에서 민감데이터가 이렇게 잡힌다"를 보여주는 데모가 목적이며,
Manifest V3 + 바닐라 JS로만 구현했고 외부 의존성(빌드툴/CDN/npm 패키지)은 0개다.

## 설치법

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램 로드" 클릭
4. 이 저장소의 `shadow-ai/` 폴더 선택

## 탐지 항목

| 카테고리 | 라벨 | 탐지 방식 |
|---|---|---|
| `rrn` | 주민등록번호 | `\d{6}[-\s]?[1-4]\d{6}` 패턴 |
| `card` | 신용카드번호 | 13~16자리 숫자열 중 **Luhn 체크섬 통과**한 것만 (오탐 감소) |
| `phone` | 휴대폰번호 | `01[016-9]-XXXX-XXXX` 형태 |
| `email` | 이메일 | 표준 이메일 정규식 |
| `apikey` | API키/시크릿 | AWS(`AKIA...`), OpenAI(`sk-...`), GitHub PAT(`ghp_...`), Slack(`xox...`), 개인키 헤더(`-----BEGIN ... PRIVATE KEY-----`) |

탐지된 값은 저장/표시 시 앞 2~4글자만 남기고 `***` 로 마스킹한다.

## 동작 모드

- **감시(monitor)**: 경고 배너만 띄우고 로그를 남기며 전송은 막지 않음 (기본값)
- **차단(enforce)**: 경고 배너 + Enter 전송/전송버튼 클릭을 가로채 실제로 차단

팝업에서 토글로 전환하고, 옵션 페이지에서 카테고리별 on/off, 로그 모드(위반 건만 vs
전체 프롬프트 저장), webhook URL을 설정한다.

## 테스트 방법

ChatGPT(`chatgpt.com`) 또는 Claude(`claude.ai`)를 열고 입력창에 아래 **가짜 테스트값**을
붙여넣어 경고 배너가 뜨는지 확인한다. (모두 실제로 유효하지 않은 예시값이다.)

| 유형 | 테스트값 |
|---|---|
| 주민등록번호 | `900101-1234567` |
| 신용카드번호 (Luhn 통과) | `4111 1111 1111 1111` |
| 휴대폰번호 | `010-1234-5678` |
| AWS 액세스키 | `AKIAIOSFODNN7EXAMPLE` |
| OpenAI 키 | `sk-abcdefghijklmnopqrstuvwx1234` |
| 개인키 헤더 | `-----BEGIN RSA PRIVATE KEY-----` |

붙여넣은 뒤 300ms 이내에 입력창 위에 빨간 경고 배너가 나타나면 정상 동작이다.
확장 아이콘을 눌러 팝업에서 위반 로그와 마스킹된 스니펫이 쌓이는지도 확인할 수 있다.

## 한계 / 다음 단계

- **커버리지**: 브라우저 확장은 이 브라우저의 지정된 사이트만 감시한다. 다른 브라우저,
  네이티브 앱, 사내 도구 API 호출, 네트워크 레벨 전송 등은 사각지대다. 진짜 DLP를
  하려면 엔드포인트 DLP나 네트워크 TLS 복호화(프록시) 같은 접근이 후순위로 필요하다.
- **전송 버튼 탐지**: 사이트별 DOM 구조가 달라 버튼 셀렉터가 휴리스틱(추정)이다.
  UI가 바뀌면 차단이 씹힐 수 있다.
- **정규식 기반**: 문맥 이해 없이 패턴 매칭만 하므로 오탐/미탐이 있을 수 있다
  (카드번호는 Luhn 체크로 오탐을 줄였지만 완벽하지 않음).
- **로컬 저장 기준**: 위반 로그는 `chrome.storage.local`에 최근 500건만 보관한다.
  webhook을 설정하면 서버로도 전송되지만 실패 시 조용히 무시한다(PoC 수준).
