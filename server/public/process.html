🛡️ vuln-agent — 전체 프로세스

런타임 노출 맥락으로 오탐을 줄이는 자율 취약점 진단 에이전트 · 2026 오픈소스 개발자대회
Bash 에이전트PHP + MySQL Docker + HTTPSOSV · KEV · EPSS 런타임·배포판 근거

각 서버의 패키지와 런타임 상태를 읽기 전용으로 수집한다. 중앙에서는 외부 노출·실행 여부와 KEV/EPSS를 함께 판단해 우선순위를 정하고 근거를 남긴다. 담당자 배정·티켓·SLA 워크플로는 범위에 두지 않는다.

3런타임 상태 — 오탐 감소의 핵심

“설치=취약”으로 전부 올리지 않는다. exposures(포트) + processes(실행/로드) 를 합쳐 각 취약점을 아래 7단계로 구분하고, 실제 노출/사용 여부로 우선순위를 가른다.

상태의미기본 등급
외부노출외부(0.0.0.0) 오픈 포트로 노출 + 사용HIGH (+KEV → CRITICAL)
로컬 세그먼트 노출mDNS 등 링크로컬 멀티캐스트 — 같은 세그먼트에만 닿고 라우터를 넘지 않음MEDIUM
방화벽 차단전체 인터페이스에 리스닝하지만 방화벽이 막아 외부 도달 불가MEDIUM
로컬리스닝리스닝하지만 127.0.0.1 만MEDIUM
실행중실행 중이나 포트 미개방MEDIUM
사용중실행 프로세스가 라이브러리 로드MEDIUM
설치만아무 프로세스도 안 씀LOW
예: 같은 openssl/glibc 취약점도 외부 서비스가 쓰면 CRITICAL, 설치만 돼 있으면 LOW/MEDIUM으로 갈린다. KEV·EPSS와 배포판 수정 근거는 이 판단을 보강한다.

4백포트 오탐 억제 — 버전 범위와 배포판 근거 교차 확인

배포판은 버전 번호를 그대로 두고 보안 패치만 이식(백포트)한다. 버전만 보는 스캐너는 이를 “취약”으로 잘못 잡는다. 매처는 finding 을 만들기 전에 버전 범위와 배포판별 수정 근거를 교차 확인한다.

범위

OSV 버전 필터

배포판 전체버전(NEVRA)과 OSV 영향 구간을 대조해 설치 버전에 실제 영향 없는 건을 제외

→
근거

배포판 수정 여부

패키지 changelog·호스트 적용 errata와 중앙의 벤더 OVAL/errata·Debian tracker를 배포판에 맞게 확인

→
분리

tb_suppressed_finding

위험 집계·화면에서는 빠지되, 숨기지 않고 근거와 함께 호스트 상세에 표시(설명가능성)

에이전트는 rpm/dpkg changelog의 CVE 줄만 전송한다. 비용이 큰 환경은 --no-changelog로 끌 수 있으며, 억제 결과와 근거는 별도 보관한다.

5보안설정 점검 (CCE)

CVE가 아닌 잘못된 설정을 본다. 기존 수집물의 security/users 정보를 판정해 호스트 상세에 PASS/FAIL/NA와 근거를 표시한다.

계열보는 것
SSH (CCE-SSH-*)sshd -T 실효값 — root 로그인·패스워드 인증·인증 시도 횟수·X11·유휴 타임아웃 등
계정·패스워드 (CCE-ACC-* / CCE-PW-*)UID 0 중복·빈 패스워드·shadow 이전, 만료일·최소길이·품질·잠금 정책
파일 권한 (CCE-FILE-*)/etc/passwd·shadow·group·gshadow·crontab 등의 소유자·권한
시스템 (CCE-UMASK · CCE-SEC-* · CCE-SVC-* …)umask·root PATH·세션 타임아웃·SELinux/AppArmor·방화벽·레거시 서비스
시간·로그·암호화 (CCE-TIME-* / CCE-LOG-* / CCE-CRYPTO-*)시각 동기화와 오차, 로그 보존기간·원격 전송, SSH 알고리즘·디스크 암호화

39개 항목을 PASS / FAIL / N/A로 구분한다. 확인할 수 없는 값은 N/A이며, SSG 연계 항목은 CIS·NIST·STIG 근거도 함께 보여준다.

6데이터 수집

UI에서 고정 커넥터 11종과 범용 API를 설정·미리보기·예약한다. 수집이 끝나면 매처가 기존 결과를 다시 계산한다.

커넥터역할채우는 데이터
NVDCVE 설명과 CVSS를 수정일 기준으로 증분 수집tb_cve
OSV설치 패키지의 영향 여부와 확인된 수정 버전 탐지tb_cve · tb_cve_affected_package
EPSSCVE별 향후 악용 확률과 백분위 보강tb_cve.epss
KEV실제 악용이 확인된 취약점 보강tb_kev_catalog
KISA보호나라 국내 보안공지와 상세 본문 수집tb_advisory
Debian데비안 릴리스별 영향 여부·수정 가능 여부 판정tb_debian_tracker
RHEL OVALRed Hat·AlmaLinux·Oracle의 벤더 수정 EVR 판정tb_vendor_errata

SSG보안설정 룰의 근거와 CIS·NIST·STIG 기준 보강tb_compliance_rule
범용 API조직별 REST 소스를 탐지·우선순위·벤더 역할로 매핑역할별 대상 테이블

7변화 추적

/changes.php 가 최근 2개 스캔의 tb_finding 를 (cve_id, package_name) 기준으로 대조해 신규 발생 · 해결됨 · 등급 상승/하락을 보여준다. 새 테이블 없이 기존 findings 비교만으로 동작한다.

8데이터 모델

수집 데이터
  • tb_host — 서버(fqdn, OS)
  • tb_scan — 내용이 달라질 때 생성하는 수집 스냅샷(원본 JSON 포함)
  • tb_scan_run — 실제 수집 실행 이력(동일 내용도 매 실행 누적)
  • tb_agent_command — 즉시·예약 실행, 진행률·heartbeat·중단 요청
  • tb_package — 패키지(버전·소스패키지·벤더)
  • tb_exposure — 노출 소켓(포트·scope·로드)
  • tb_process — 실행 프로세스(exe·로드)
취약점 · 판정 · 계정
  • tb_cve — CVE(cvss·epss·요약)
  • tb_kev_catalog — KEV 등재
  • tb_cve_affected_package — 영향 패키지·수정 버전
  • tb_finding — 판정(등급·상태·근거)
  • tb_advisory — 국내 보안공지
  • tb_feed_connector / _collection_log — 커넥터·이력
  • tb_user — 웹 계정
  • tb_activity_log — 감사로그(로그인·CRUD·ingest 기록)
오탐억제 · 설정점검 · 권한
  • tb_pkg_changelog_cve — changelog 의 CVE 수정 기록(백포트 근거)
  • tb_suppressed_finding — 백포트로 억제된 finding(근거 포함)
  • tb_cce_finding — 보안설정 점검 결과(PASS/FAIL/NA)
  • tb_role_permission — 역할×메뉴 허용 여부(설정형 RBAC)
  • tb_api_token — Export API 토큰(SHA-256 해시만 저장)

테이블은 tb_ 접두사를 통일하고, 독립 생명주기를 가진 주요 테이블은 감사 4컬럼(created_at/updated_at/is_deleted/deleted_at)을 둔다. 삭제는 하드삭제 대신 소프트삭제(is_deleted=1, findings 등 재계산 캐시 테이블은 예외).

9배포 (agent-side push, HTTPS)

중앙이 호스트로 접속하지 않는다. 각 서버가 로컬에서 수집한 뒤 아웃바운드 HTTPS로 전송한다.

① 중앙 서버 (내부 서버, Docker + Caddy)
./compose_runner.sh init
./compose_runner.sh prod up -d --build
Caddy가 TLS를 종료하고 내부 web:80으로 프록시한다.

② 대상 서버 (에이전트 설치 + 호스트별 수집 주기)

sudo bash install-agent.sh
  중앙 서버 주소 → https://<운영-도메인>:8080/ingest.php
  전송 토큰 → 에이전트 키 화면에서 호스트별 발급 · 수집 주기 → hourly
systemd 서비스는 명령을 poll하고 설정 주기로 수집한다. cron 폴백은 정기수집만 가능하며 즉시·예약·중단 명령은 지원하지 않는다. 토큰은 <prefix>/etc/agent.env(600)에 저장한다.

③ 웹 — 운영 도메인에서 취약점·상태·감사로그를 확인한다.

10Export API

외부 시스템이 스캔 결과를 가져갈 수 있는 읽기 전용 API다.

GET /export.php — JSON/XML, 호스트·심각도·KEV·EPSS 필터 지원
인증: X-API-Token 또는 Authorization: Bearer
토큰은 /api-tokens.php에서 발급하며, 원문은 발급 시 한 번만 표시한다.

11권한 (설정형 RBAC)

admin / operator / user 역할을 제공한다. admin은 전체 허용이며, operator·user의 메뉴 권한은 /permissions.php에서 설정한다.
