# UI 디자인 시스템

> 문서 기준: 2026-08-20.
> 정본은 `server/public/assets/app.css`(색·레이아웃)와 `server/src/view/`(마크업)다.
> `/styleguide.php` 에서 실제 공통 헬퍼 결과를 Light/Dark 로 비교한다.

이 문서는 **규칙만** 적는다. 값(색상코드·px)은 `app.css` 하나가 소유한다 —
여기 숫자를 옮겨 적으면 두 벌이 되어 갈라진다.

## 텍스트 예산

**판정 한 줄**: 그 줄을 지웠을 때 잃는 것이 **값**이면 남기고, **설명**이면 지운다.
문장 끝이 `~합니다`·`~세요`인데 값이 안 들어 있으면 대개 설명이다.

| 지우는 것 | 왜 | 값은 어디로 |
|---|---|---|
| **부제**(제목 아래 설명 줄) | 화면이 무엇인지는 제목과 사이드바가 말한다. `vg_page_title()` 에는 부제 인자 자체가 없다 | 경계·기준·기본 범위는 전부 걷었다 |
| **결론 배너** | 바로 아래 표·KPI·배지가 가진 값을 문장으로 되풀이한 것 | 목록은 값만 세우고 판단은 상세에서 한다(결론 배너 헬퍼 `vg_verdict` 는 걷어냈다) |
| **제목 + 불릿짜리 해설 배너** | 불릿이 "이 화면을 어떻게 읽나" 면 배너째 | 그 안의 **수치 기준·판정 규칙은 값이므로 옮긴다** — 열 머리글의 `title`, 배지의 `title`(`vg_nofix_threshold_help()` 가 그 예) |
| 컨트롤 옆 사용법 | 버튼이 이미 말한다 | 남길 값만 버튼 `title` 로 |
| **KPI 타일 안의 문장·타일 밑 기준 줄** | 값이 없으면 `–` 하나면 된다 | "왜 없는지"는 `vg_kpi_strip()` 의 `title` 키로 |
| **카드 제목 옆 `— 설명`** (상세 화면도 같다) | 제목이 이미 말한 것의 되풀이 | `<span class="why">` 자리에 남는 건 값뿐 — 건수·현재값·절단 고지·링크·배지 |
| 열 머리글의 괄호 설명 | `근거 (무엇을 보고 판정했나)` → `근거` | 풀어 쓸 것은 머리글 `title` 로 |
| 표 셀의 문장·분모 설명절 | 셀에는 배지·숫자·짧은 명사구만 | 분모는 그 행 게이지의 `title`, 더 필요하면 `근거 →` 가 가리키는 상세가 답한다 |
| 목록 이름 칸에 이은 식별자 | 고르는 축은 하나면 된다 | 나머지는 상세가 갖는다 |
| 화면 자체의 메타 설명(`이 화면이 증명하는 것은 …`) | — | 삭제 |

**지우지 않는 예외** — 산문처럼 보여도 값인 줄이다.

- **지금 좁혀 본 범위**(탐지 결과의 `호스트 X · scan #12` + 해제 링크). 숨기면 0건이 "안전"으로
  읽힌다. 안 좁혔을 때는 그 줄도 그리지 않는다.
- **"0건은 안전이 아니라 판정 불가"·수집 실패·상한 절단 고지.** 이 제품이 못 채운 것을 밝히는 줄이다.

### 같은 값을 한 화면에 두 번 두지 않는다

- 한 행의 링크 둘이 **같은 URL** 로 가지 않게 한다. ID 열과 제목 열이 같은 상세로 가는 것은
  **예외로 허용한다** — 누르는 면적을 ID 한 조각으로 좁히지 않기 위한 의도다.
- 표 위 KPI 와 그 아래 범례·요약이 같은 수를 말하지 않게 한다(`vg_legend()` 의 `n` 은 위에
  같은 건수의 KPI 가 없을 때만 준다).
- `<details>` 의 `summary` 에 바로 위 카드 제목을 되풀이하지 않는다.
- 한 대상에 설명이 둘이면 **범위를 온전히 말하는 쪽만** 남긴다.

## 문구

컨트롤(고르고 누르는 것)은 **단어**로 쓰고, 문장은 **안내에만** 쓴다. 컨트롤 자리에 말을 거는
문장(`고르세요`)이 들어가면 값처럼 읽히지 않아 훑을 때 걸린다.

- 셀렉트 옵션·버튼·탭·필터 라벨·표 머리글은 명사(구) 또는 동사 한 단어. 분명히 해야 하면
  `호스트 선택`처럼 명사구로 늘리되 `~하세요`·`~해 주세요` 는 쓰지 않는다.
- 버튼은 하는 일을 동사로 쓰고 누른 뒤 확인 문구도 같은 동사를 쓴다(`발급` → `토큰이 발급되었습니다`).
  같은 동작에 화면마다 다른 동사를 쓰지 않는다.

### 셀렉트 빈 값 옵션의 정본

`value=""` 옵션은 **다섯 갈래로 갈려 있었다**(`고르세요`·`미지정`·`미검토`·`변경 안 함`·`미지정(확정 해제)`).
빈 값이 **무엇을 뜻하는지**로 다섯 가지가 아니라 아래 다섯 **역할**로 가른다 — 역할이 같으면 표기도 같다.

| 역할 | 정본 | 쓰는 곳 |
| --- | --- | --- |
| 이 축으로 좁히지 않음(필터) | `전체 <대상>` | `vg_toolbar()`의 필터 셀렉트 |
| 기본 정렬(정렬 셀렉트) | `<정렬명>(기본)` | 목록의 정렬 셀렉트 |
| 아직 안 골랐음, 골라야 함(required) | `선택` | 등급 일괄 확정의 보안등급 |
| 비워 두면 값 없음으로 저장됨 | `미지정` | 자산 상세의 중요도·제9조 해당 호·공개 상태 |
| 일괄 편집에서 이 항목은 건드리지 않음 | `변경 안 함` | 등급 일괄 확정의 중요도 |

- `전체`는 **`전체 <대상>` 어순으로 고정한다** — `심각도 전체`처럼 뒤에 붙이지 않는다.
- `미검토`는 `미지정`으로 모은다. 둘 다 "저장된 값이 없다"는 같은 상태이고, 상세 화면에서는
  이미 둘 다 `–` 하나로 표시하고 있었다.
- `변경 안 함`은 남긴다. "그대로 둔다"는 **하나의 선택지**이지 값이 없는 상태가 아니다.
- 빈 값을 고르면 기존 확정이 풀리는 등 부작용이 있으면 괄호로만 덧붙인다: `미지정(확정 해제)`.

### 입력 placeholder 는 지시가 아니라 예시다

- `토큰 이름(용도)을 입력하세요`가 아니라 `예: AI 보고서 생성기`. 예시 접두는 `예:` 로 통일한다.
- 비워 뒀을 때의 동작은 예시가 아니라 규칙이므로 그대로 서술한다: `비우면 호스트명으로 자동 지정`.
- 제약(길이·형식)은 placeholder 가 아니라 라벨 옆 `.why` 에 둔다 — placeholder 는 입력하는 순간
  사라져서 제약을 거기 두면 볼 수 없다.

### 문장이 허용되는 곳 · 금지

허용: 오류·경고·확인 메시지와 빈 상태(`vg_empty()`)의 힌트 한 줄. 여기서도 **무엇이 잘못됐고
어떻게 고치는지**만 쓴다(`패치된 라이브러리를 적용하려면 관련 프로세스를 재시작하세요`).

금지: 화면 자체를 설명하는 메타 문장 · 라벨과 힌트에서 같은 말 두 번 · 같은 대상을 화면마다 다른
말로 부르기(`비번`/`비밀번호`) · 영문 기술 용어(CVE·KEV·EPSS·SBOM·CVSS·SSH·fqdn)를 억지로 한글로 옮기기.

## 토큰

두 테마가 **같은 이름**을 공유하고, `<html data-theme="dark">` 가 값만 갈아끼운다. 컴포넌트 CSS 는
토큰만 참조하므로 테마 전환에 규칙을 손댈 필요가 없다. **다크 절에는 색만 오버라이드하고 새 토큰을
선언하지 않는다.** 표 밀도는 별도 축이다 — `<html data-density="compact">` 가 `--row-h`·`--cell-py`
둘만 갈아끼운다.

톤은 4종 세트다: `--crit`(원색·면) / `--crit-fg`(글자) / `--crit-bg`(옅은 틴트) / `--crit-bd`(테두리).
나머지 톤도 같은 꼴이다.

| 축 | 토큰 | 규칙 |
|---|---|---|
| 표면 | `--bg` `--surface` `--surface-2` | 세 단계. 내려간 입력·코드 면은 파생 토큰 `--sunken` 만 쓴다 |
| 경계 | `--line` `--line-2` | 격자는 "보이라고" 있다. 강조가 필요한 경계만 `--line-2` |
| 글자 | `--text` `--text-2` `--muted` `--muted-2` | `.why`(근거)·표 보조 문구가 `--muted`. `--muted-2` 는 그보다 더 물러난 자리 |
| 강조 | `--accent` `--accent-2` `--ring` `--danger` | `--ring` 은 포커스 링 그림자값이다(색이 아니다) |
| 심각도 | `--crit` `--high` `--med` `--low` (각 `-fg`/`-bg`/`-bd`) | 채도가 계단이다. LOW 는 건수가 압도적이라 회청으로 물러나 있다 — 면적이 서열을 뒤집지 않게 |
| 상태 | `--ok`(+`--ok-hover`) `--muted-fg` `--muted-bg` `--muted-bd` `--info-fg` `--info-bg` `--info-bd` `--purple` | 배지·범례가 쓰는 톤 어휘. `info` 톤은 원색 없이 3종뿐이라 면으로 칠하지 않는다 |
| 버튼 | `--btn-bg` `--btn-fg` `--btn-hover` | 중립 버튼(초기화·ghost) 전용 — 흰 배경 위에서 흰 글자가 될 수 없어 따로 둔다 |
| 형태 | `--r-xs` `--r-sm` `--r-md` `--r-lg` `--shadow` `--shadow-lg` | 그림자는 이 둘만. 입체감은 그림자 + 윗면 1px 하이라이트로만 준다(실제 3D 변환은 안 쓴다) |
| 간격 | `--sp-1`~`--sp-6` | 카드 패딩·블록 여백을 한 축으로. 밀도를 조일 때 여기만 고친다 |
| 본문 크기 | `--fs-xs` `--fs-sm` `--fs-md` `--fs-lg` `--fs-xl` | 다섯 단만 |
| 디스플레이 숫자 | `--fs-num-sm` `--fs-num` `--fs-num-lg` | 아래 별도 절 |
| 치수 | `--ctl-h` `--topbar-h` `--toolbar-h` `--row-h` `--cell-py` `--cell-px` | 화면이 값을 덮지 말고 **토큰을 갈아끼운다**(`.page--assets { --cell-px: … }`). `--toolbar-h` 는 sticky 툴바와 sticky 표 머리글이 서로를 가리지 않게 고정한 값이다 |
| 범주형 색 | `--cat-1`~`--cat-6` | 아래 별도 절 |
| 차트 표면 | `--chart-grid` `--chart-axis` `--chart-tip-bg` `--chart-tip-bd` | **전부 기존 토큰을 가리키는 별칭이다**(새 색 아님). 그래서 다크 절에 다시 적을 것이 없다 |
| 아이콘 타일 | `--tile` `--tile-r` `--tile-ico` | **크기만** 토큰이다. 배경·전경은 새 색을 만들지 말고 톤 쌍(`--crit-bg` + `--crit-fg` …)을 쓴다 |

`--tip-anchor` 는 전역 토큰이 아니라 `.info-tooltip` 안에서만 사는 지역 변수다(툴팁 화살표 위치).
전역 토큰처럼 다른 컴포넌트에서 참조하지 않는다.

> **없는 토큰을 쓰지 않는다.** 리스킨 레이어가 여러 겹 쌓이는 동안 `app.css` 에 **정의가 없는 이름**을
> 참조하는 규칙이 남아 화면이 실제로 깨진 적이 있다. 새 이름을 쓰기 전에 정의가 있는지 먼저 본다 —
> 정의 없는 이름을 문서에 적으면 그 실수가 규격으로 굳는다.

### 디스플레이 숫자는 세 단뿐

본문 스케일과 나눠 둔 이유는 이 값들이 글이 아니라 **지표**라, 본문 밀도를 조일 때 같이 줄면 안 되기 때문이다.

- `--fs-num-sm` — 보조 숫자. 목록 화면 위의 `kpi--sm`, 요약 블록의 `strong`.
- `--fs-num` — 기본 숫자. 대시보드 `kpi`, 도넛 가운데, `stat-grid` 의 점수.
- `--fs-num-lg` — 가장 큰 숫자. 상세 사이드바의 `score`, 퍼널 마지막 칸.

새 숫자를 그릴 때 `rem` 을 직접 쓰지 않는다. 세 단으로 안 되면 단을 늘리는 게 아니라 자리를 다시 본다.
(예전엔 1.25~2.1rem 열한 개가 같은 역할을 하며 흩어져 있었다.) 네 단이 필요한 유일한 자리는
퍼널(`funnel__step--s1~s4`)이다 — 크기 자체가 포함관계를 그리는 그림이라, 새 값을 만들지 않고
`--fs-lg → --fs-num-sm → --fs-num → --fs-num-lg` 로 잇는다.
예외는 데이터 시각화 SVG 의 좌표계 글자와 아이콘의 광학 크기뿐이다.

### 범주형 색은 심각도와 다른 축이다

심각도 4색은 의미가 고정돼 있어(CRITICAL=빨강) '조치 상태별 분포' 같은 **의미 없는 범주**에 쓸 수 없다.
그래서 심각도가 쓰는 빨강·주황·앰버·회청을 피한 6색을 따로 둔다.

- 순서가 곧 배정 순서다(1번부터 채운다). 색을 안 주면 `chart-kit.js` 가 `--cat-1` 부터 배정한다.
- `--cat-6` 은 **"기타·미분류" 고정 슬롯**이다. 범주가 7개 이상이면 차트로 그리지 말고 상위 5 + 기타로 접는다.
- 다크에서는 **명도만** 올린다. 색상을 돌리면 같은 범주가 테마마다 다른 색이 된다.

## 버튼 규격

색 계열(`primary`·`ghost`·`secondary`·`danger`·`warn`)은 **서열**을 말하고, 크기 클래스는 **자리**를 말한다.
자리가 같으면 크기도 같아야 한다 — 한 툴바·한 표 행 안에서 크기가 섞이면 그것만으로 눈에 띈다.

| 자리 | 규격 |
|---|---|
| 페이지 머리글의 주 동작(모달 열기, 발급, 추가, 저장) | `btn btn--sm btn--primary` |
| 툴바·form-bar의 보조 동작(초기화, 내보내기, 일괄 작업) | `btn btn--sm btn--ghost` |
| 표 행 안의 인라인 동작(편집·이력·삭제) | `btn btn--xs btn--ghost` |
| 모달 푸터 | `vg_modal_foot()`가 소유한다 — 페이지가 크기 클래스를 직접 쓰지 않는다 |
| 로그인·프로필처럼 폼 하나가 화면인 제출 버튼 | `btn btn--primary btn--block`(크기 없음 = 기본 단) |
| 파괴적 동작(삭제·폐기) | 위 크기를 그대로 두고 `btn--danger`만 바꾼다 |

- 페이지 머리글 버튼은 `vg_page_title(..., ['actions' => …])`로 넣고, 모달을 여는 것이면
  `vg_modal_btn()`을 쓴다(기본값이 이미 `btn btn--sm btn--primary`다).
- 모달 푸터가 크기 클래스를 안 쓰는 것은 의도다 — 기본 `.btn` 한 단으로 모든 모달이 같은 크기·정렬을
  갖는다. `extra`로 넘기는 보조 버튼도 같은 이유로 크기 클래스를 붙이지 않는다.
- `btn--secondary`는 `ghost`와 합치지 않는다. `ghost`는 무채색 외곽선이고 `secondary`는 강조색 외곽선이라
  "주작업은 아니지만 눌러 보라"는 중간 서열을 말한다(연결 미리보기, 표 행의 편집). `/styleguide.php`에서
  두 색이 실제로 갈리는지 확인할 수 있다.

## 공통 컴포넌트

마크업은 `server/src/view/` 가 소유한다. **새 배지·빈 상태·페이저 마크업을 페이지에 직접 만들지 않는다.**
`components.php` 는 진입점(파사드)일 뿐이고 구현은 책임별로 `view/components/` 아래 7개 파일에 있다 —
부르는 쪽은 예전처럼 `components.php` 하나만 require 하면 된다.

| 파일 | 헬퍼 | 소유하는 것 |
|---|---|---|
| `components/page.php` | `vg_page_title()` `vg_hero()` `vg_subtabs()` | 화면 뼈대. 제목은 **카드가 아니라 얇은 헤더 줄**이다 |
| `components/table.php` | `vg_table()` `vg_toolbar()` | 행 높이·정렬·말줄임·GET 검색 폼. 긴 원문은 상세나 툴팁으로 |
| `components/paging.php` | `vg_page_nav()` `vg_perpage_select()` `vg_qs()` | 목록의 URL 상태. 한 화면에 페이저가 여럿이면 파라미터 이름을 인자로 준다 |
| `components/signal.php` | `vg_kpi_strip()` `vg_signal_slots()` `vg_legend()` `vg_decision_flow()` | 지표와 "색이 무슨 뜻인가" |
| `components/notice.php` | `vg_alert()` `vg_empty()` `vg_flash_take()` | 알림·플래시·빈 상태 |
| `components/modal.php` | `vg_modal_btn()` `vg_modal_open()` `vg_modal_foot()` | 모달 한 벌 |
| `components/prop.php` | `vg_local_href()` `vg_copy_btn()` `vg_sbom_links()` | 소품. 내부 링크 검증이 여기 있다 |
| `view/icons.php` | `vg_icon()` | 인라인 SVG 아이콘 데이터(**데이터만**) |
| `view/charts.php` | 아래 "그림" 절 | 도넛·추이·순위·Chart.js |
| `format/badge.php` | `vg_badge()` `vg_meter()` | 배지·게이지 |

- `vg_kpi_strip()` 은 칸 수와 무관하게 같은 격자·톤·0값 규칙을 쓴다. 링크는 앱 내부 경로만 허용한다.
  `icon` 키를 주면 아이콘 타일(`--tile`)이 붙고, 안 주면 지금까지처럼 숫자+라벨만 그린다.
- `vg_signal_slots()` 은 노출→악용→등급→조치 순서를 고정한다. CCE 처럼 축이 없으면 `state=na`,
  아직 값이 없으면 `state=unknown` 으로 조용히 남긴다.
- `vg_empty()` 의 `icon` 은 `icons.php` 의 **이름**이다 — 이모지·기호 문자를 넣지 않는다.
  환경에 따라 컬러 이모지 폰트로 렌더돼 `currentColor` 를 안 따라가고, 폰트에 없으면 두부(□)가 된다.
- `vg_alert()` 에 `details` 를 주면 딸린 목록을 **접어서** 붙인다. 닫혀 있어도 HTML 에는 그대로
  있어 `Ctrl+F`·스모크 단언이 같이 산다 — 목록이 길다고 지우지 않는다.

### 카드 목록

행이 세로 공간을 필요로 하는 목록(컨테이너·통제 매핑·CCE 카탈로그·U-코드·의존성 루트)은
표가 아니라 **카드 그리드**(`.ctrcard` / `.u-card` + `.ctrcard-grid` / `.u-grid` / `.ctree__list`)로 그린다.
표로 두면 판정 칸만 넓은데 좁은 열과 나란히 눌려 잘린다.

- **카드 머리는 두 줄로 고정한다.** `__title`(이름) 이 항상 첫 줄, `__badges` 가 항상 그 아래다.
  한 인라인 흐름에 두면 제목 길이에 따라 배지가 붙었다 밀렸다 하며 위치가 들쭉날쭉해진다.
  배지가 없는 카드도 `__badges` 래퍼는 렌더한다(비우기만) — 조건부로 빼면 카드 높이가 흔들린다.
- **위험 등급은 왼쪽 띠(`tone-*`)가 말한다.** 그 축은 위험 등급 전용이라 "루트/대상" 같은 **다른 축**을
  얹지 않는다 — 색이 필요하면 별도 modifier 로 둔다(`.ctrcard--dep-root`).
- **2차 정보는 접는다**(`.ctrcard__detail`). 이미지·OS·다이제스트·SBOM 링크는 심각도보다 눈에 덜 띄어야 한다.
- 하위 트리가 카드 안에 중첩되는 org-chart(`depgraph.php`)는 카드 뼈대를 그대로 쓰고 1열로만 강제한다.

### 그림으로 설명하는 자리

**외부에서 받아오지 않는다.** CSP 가 `default-src 'self'` 라 CDN 스크립트·아이콘 폰트·외부 스프라이트는
구조적으로 못 쓴다(폐쇄망 배포 전제이기도 하다). 필요한 라이브러리는 **저장소에 벤더링해 로컬로 서빙**한다.

| 형태 | 무엇으로 | 규칙 |
|---|---|---|
| 형태가 고정된 차트 — 심각도 도넛(`vg_sev_donut()`)·판정 분포(`vg_result_donut()`)·리소스 추이(`vg_resource_trend()`)·순위 막대(`vg_rank_bars()`)·증감 막대(`vg_change_bars()`) | 순수 `<svg>` | 색은 토큰(`--crit` 등)을 그대로 참조한다 — 팔레트를 바꾸면 차트도 따라온다 |
| 축·범례·툴팁·반응형이 필요한 일반 차트 | `vg_chart()` → 벤더링한 Chart.js(`assets/vendor/chartjs`) | 화면은 데이터와 형태만 말한다. 팔레트·격자색·툴팁·다크 대응은 `assets/js/chart-kit.js` 한 곳이 갖는다 |
| 아이콘 | `vg_icon()` 의 인라인 SVG | `currentColor` 로 그려 테마를 따라간다. 색을 아이콘에 하드코딩하지 않고 크기는 CSS(`.vg-ico`)가 정한다. **이모지로 대체하지 않는다** |
| 비율·점수 | `vg_meter()` | 새 마크업으로 다시 만들지 않는다. 폭 `width:N%` 만 인라인 style 예외다 |
| 색의 뜻 | `vg_legend()` | 점과 단어로만 말한다(문장 금지). 톤 어휘 밖의 색을 새로 만들지 않는다 |

- `vg_chart_assets()` 는 **차트를 그리는 화면만** 부른다(`vg_header()` 직후). 전 화면에 vendor 를 물리지
  않으려고 `layout.php` 에 넣지 않았다. 여러 번 불러도 한 번만 나간다.
- 사양은 `data` 속성으로 넘긴다 — CSP 가 인라인 `<script>` 를 막기 때문이다.
- **노드-링크 그래프 라이브러리(d3-force·cytoscape 류)는 들이지 않는다.** 의존성 화면은 접이식 트리와
  루트별 카드로 그린다(`architecture.md` 의 depgraph 결정).
- 화면 상단 가로 도식(`vg_explain_flow`)은 **없앴다**(2026-08-17). 도식이 들고 있던 숫자가 같은 화면의
  KPI 줄·제목 건수와 겹쳐 화면마다 같은 값을 두 번 세고 있었다 — 새로 만들지 않는다.
  건별 판단 근거는 `vg_decision_flow()` 가 갖는다.

## 목록과 상세의 분담

**목록은 결정에 필요한 열만, 상세가 전부를 갖는다.**
목록 표의 열은 "이 행을 열어볼지 말지"를 정하는 데 필요한 것만 둔다 —
식별자 · 위험도 · 상태 · 시각 정도다. 나머지 값은 지우는 게 아니라 상세 화면으로 옮긴다.
목록 표 열 상한은 **7열**로 둔다(체크박스 열 제외).

- **페이지 크기 기본값은 화면마다 다르지 않다.** 목록도 상세 안의 목록도 `UI_PER_PAGE_DEFAULT`
  하나를 쓴다(기본 10). 상세 전용 기본값은 없앴다 — 자세한 것은
  [`ui-configuration.md`](../ui-configuration.md).
- 상세는 히어로(`vg_hero()`)로 "무엇을 보고 있나 + 얼마나 위험한가"를 먼저 세우고, 갈래는
  `vg_subtabs()` 로 나눠 담는다. 첫 화면에 다 쏟지 않는다.

## Phase 2 적용 규칙

핵심 화면은 KPI, 표, 신호 슬롯 순으로 값을 배치한다(결론 문장을 앞에 세우지 않는다).
데이터·쿼리는 바꾸지 않고 기존 표시값을 공통 슬롯으로 옮긴다. 네 축 중 없는 값을 추정해 만들지 않는다.
